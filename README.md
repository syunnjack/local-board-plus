Canonical domain: https://syunnjack.github.io/local-board-plus/

## Repository Name

local-board-plus

## Features

- 地域掲示板とアンテナサイト
- UGC投稿、確認待ち、確認済みステータス
- モデレーションルール
- SEO/AIO/LLMO向けFAQ、即答ブロック、構造化データ
- robots.txt / sitemap.xml / llms.txt
- 地域スポンサー、掲示板広告、イベント告知、確認済み掲載、周辺送客の収益導線
